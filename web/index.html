ABOUT / 02

Made for the way you write.

Onnoy is a direct Unicode keyboard for Bangla, Assamese, and Kokborok written in the Bengali script. It uses physical US-QWERTY positions, with Shift and Right Alt (AltGr) for alternate characters. There is no phonetic transliteration step.

⌨

Native on desktop

Linux XKB, Windows keyboard layouts, and macOS input sources work without a background input method.
