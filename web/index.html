03 / GET ONNOY

Make it your own.

Built from a single open-source keymap. Install a native operating-system keyboard; no background input app required.

NATIVE LINUX
⌨

Linux · XKB

A generated XKB layout, without a third-party input method. Desktop registration can vary; see the installation guide.

Linux guide ↗
NATIVE macOS
⌘

macOS · Input Source

System-native .keylayout with a macOS installer package generated on macOS. Package signing and on-device validation remain pending.

macOS guide ↗
NATIVE WINDOWS
⊞

Windows · Keyboard DLL

Windows KLC source. Building an installable layout currently requires MSKLC on Windows; no extra software is needed after installing the compiled native layout.

Windows guide ↗

The native formats do not depend on Keyman. Compatibility and real-device packaging still need verification.
